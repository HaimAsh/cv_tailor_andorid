# מתאים קורות חיים (אפליקציה לטלפון)

אפליקציה שמתקינים מהדפדפן, בלי Google Play. נותנים לה את קורות החיים ואת הקישור למשרה, והיא מחזירה גרסה של קורות החיים שמותאמת למשרה הזו. את הגרסה אפשר להוריד כ-Word או כ-PDF, או לשתף ישירות לוואטסאפ ול-Gmail.

הכול רץ בטלפון עצמו. המפתח וקורות החיים לא עוברים דרך שום שרת חוץ מ-Gemini של Google.

## העלאה ל-GitHub Pages

1. נכנסים ל-github.com ולוחצים **New repository**.
2. נותנים לו שם, למשל `cv-tailor`, ובוחרים **Public**. ב-GitHub Pages בחינם רק repository ציבורי יכול להתפרסם.
   * אין בקוד שום מידע אישי. המפתח שלך נשמר רק בטלפון.
3. בעמוד של ה-repository החדש לוחצים **uploading an existing file**.
4. מחלצים את ה-zip במחשב, ו**גוררים את התוכן של התיקייה** (לא את התיקייה עצמה) לחלון הדפדפן. גוררים גם את התיקיות `vendor`, `fonts` ו-`icons`, ולוחצים **Commit changes**.
   * `index.html` צריך להיות ישירות ברמה העליונה של ה-repository.
5. נכנסים ל-**Settings**, ואז ל-**Pages**. תחת **Branch** בוחרים `main` ו-`/ (root)`, ולוחצים **Save**.
6. אחרי דקה או שתיים מופיעה כתובת כמו `https://השם-שלך.github.io/cv-tailor/`.

## התקנה בטלפון

1. פותחים את הכתובת ב-Chrome בטלפון.
2. בתפריט (שלוש הנקודות) בוחרים **התקנת אפליקציה** או **הוספה למסך הבית**.
3. פותחים את האפליקציה מהאייקון, לוחצים **הגדרות** ומדביקים את מפתח ה-API של Gemini מ-https://aistudio.google.com/apikey

## שימוש

1. **קורות חיים.** מעלים קובץ Word או PDF, או מדביקים טקסט.
2. **המשרה.** מדביקים קישור ולוחצים **קריאת המשרה**. Gemini קורא את הדף בעצמו. כדאי להציץ בטקסט שהוא הביא ולוודא שזו המשרה הנכונה.
   * **LinkedIn** חוסם קריאה אוטומטית, ושם צריך להעתיק את תיאור המשרה ולהדביק ידנית.
3. **התאמה.** לוחצים **התאמת קורות החיים למשרה**. זה לוקח בערך חצי דקה עד דקה.
4. **שמירה.**
   * **Word:** הורדה או שיתוף ישיר.
   * **PDF:** לוחצים **שמירה כ-PDF**, ובחלון ההדפסה בוחרים את המדפסת **שמירה כ-PDF**. ה-PDF מכיל טקסט אמיתי, כך שמערכות ATS יכולות לקרוא אותו.

**כמה דברים שכדאי לדעת:**
* **שמירה במכשיר.** הטקסטים והתוצאה האחרונה נשמרים במכשיר, כך שאפשר לסגור את האפליקציה ולחזור אליה.
* **בלי אינטרנט.** האפליקציה נפתחת גם בלי חיבור, אבל ההתאמה עצמה דורשת חיבור.
* **הכלי לא ממציא ניסיון.** דרישות מהמשרה שאין לך מופיעות ב"מה השתנה" ולא נכנסות לקורות החיים.

## עדכון גרסה

אחרי שמשנים קבצים ב-GitHub, צריך להעלות את המספר ב-`VERSION` בקובץ `sw.js`, למשל מ-`cvt-v1` ל-`cvt-v2`. אחרת הטלפון ימשיך להציג את הגרסה השמורה. אחרי העדכון, סוגרים ופותחים את האפליקציה פעמיים.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה המסכים |
| `app.js` | הלוגיקה: קריאת קבצים, הקריאות ל-Gemini (כולל ה-prompt), יצירת Word והדפסה ל-PDF |
| `styles.css` | עיצוב האפליקציה, קורות החיים והדפסה |
| `sw.js` | שמירת האפליקציה במכשיר לעבודה בלי אינטרנט |
| `manifest.webmanifest` | השם, האייקון והצבעים של האפליקציה המותקנת |
| `vendor/` | ספריות: docx (יצירת Word), mammoth (קריאת Word) ו-pdf.js (קריאת PDF) |
| `fonts/` | הגופנים Heebo ו-Frank Ruhl Libre |
